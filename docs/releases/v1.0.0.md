# 🚀 QueueLess — v1.0.0

> Codename *Nova* - Sight

The first pre-release of **QueueLess**—a cloud-native, token-based queue management system built for real-world organizations.

## ✨ What's Included

### 🎫 Core Queue System

* Walk-in token issuance with email notification and tracking link.
* Real-time queue state via Firebase Realtime Database—no page refresh required.
* Priority token support with prioritized serving.
* Token expiry, skip, and no-show handling.
* Customer-facing token tracking page (`/token/:id`) featuring:

  * Live queue position
  * Estimated wait time (ETA)
  * QR code
  * WhatsApp sharing
  * Browser push notifications
* Confetti animation and sound alert when a customer's token is called.

### 🛠️ Admin Panel

* Secure JWT-based administrator authentication.
* Queue control dashboard with pause, resume, reset, call-next, and skip actions.
* Multi-service queue management with independently managed service counters.
* **AI Auto Mode** using machine learning to predict optimal call intervals from historical traffic data.
* Analytics dashboard with per-hour and per-service traffic heatmaps.
* Staff management for creating, viewing, and removing staff accounts.

### 👥 Staff Portal

* Staff authentication using username/password or PIN.
* Per-counter queue view with call-next and no-show controls.
* Live staff presence indicator (online/offline) visible to administrators.

### 📺 Public Display

* Full-screen display page (`/display`) optimized for TVs and kiosks.
* Live "Now Serving" board grouped by service.
* Real-time clock and queue statistics.

### ☁️ Infrastructure

* React 18 + Vite frontend deployed on Vercel.
* Node.js + Express backend deployed on Render.
* Firebase Realtime Database (Singapore region) for live queue synchronization.
* MongoDB Atlas for analytics and historical data persistence.
* GitHub Actions CI/CD pipeline.
* Firebase Analytics integration.

---

*QueueLess is a cloud-native queue management system. No application installation is required—customers can access the service from any modern web browser.*
